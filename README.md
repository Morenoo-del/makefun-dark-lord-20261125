A 100-word villain monologue for make.fun's "The Tired Dark Lord" bounty: a dark lord who forged the Ember Crown, wore it three hundred years, and would now rather offer the hero a cup of tea than a final battle. The weariness lives in the deflections — the freshly mopped floor, the gossiping ravens, the kettle already on — never in a plain statement of it.

## Run it

```sh
python3 main.py
```

This writes the monologue to `/output/entry.txt`.
